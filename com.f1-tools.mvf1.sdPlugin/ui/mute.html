The mute action will mute the audio of all players or the selected player, when unmuted the previous volume is maintained.

If effects all players the action will toggle mute on all players. The mute state players are set to is the opposite of the current state of the highest priority player (International > F1 Live > Oldest Player).

If effects teh selected player the action will toggle mute on the player selected in the player picker.

If neither option is selected the action will toggle mute on the selected player.
