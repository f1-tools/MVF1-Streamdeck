The Play/Pause action allows you to toggle the play/pause state of either all of the players or a single player that is selected in the player selector that appears after the action is triggered. If neither option is selected the action will play/pause all players.

If the action is effecting all players then the Sync setting will determine if there is an automatic sync after the play/pause action is triggered. This setting is useful because the pause/play action does NOT effect the live timing data stream, but a sync will pause/play the live timing data stream to match the players. If neither option is selected the action will sync after every play/pause.
