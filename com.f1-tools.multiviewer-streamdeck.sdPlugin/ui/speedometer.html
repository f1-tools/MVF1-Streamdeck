The Speedometer action will toggle the speedometer on all onboard camera players or a single onboard camera player.

If effects all players it will toggle all players speedometers. It is NOT guaranteed that all players will toggle to the same value, they will toggle to the opposite of whatever each player was previously.

If effects the selected player it opens the player selector to allow you to choose which player to toggle the speedometer on.

If neither option is selected the action will toggle all players speedometers.
