The Rewind action will rewind all players or a single player by the number of seconds specified above.

If effects all players holding the button will continue to rewind all players until the button is released. Sync is not guaranteed to be maintained across all players. It is recommended to seek with the player with the highest priority (International > F1 Live > oldest player) in mind and then manually sync the other players and data stream afterwards.

If effects the selected player it opens the player selector to allow you to choose which player to skip backward on. It will only skip backward on the selected player once, holding down the button will NOT continue to skip backward.

If neither option is selected the action will rewind all players.
