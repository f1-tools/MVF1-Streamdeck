The Cycle Header Mode action will cycle which header is visible on all onboard camera players or a single onboard camera player. If there is no change, click again and there will be a change (this is due to the fact that it is impossible to query the current state of the header, so it was probably just set to what it already is).

If effects all players will cycle the header on all players. It IS guaranteed that all players will change to the same value.

If effects the selected player it opens the player selector to allow you to choose which player to cycle the header on.

If neither option is selected the action will cycle the header on all players.
