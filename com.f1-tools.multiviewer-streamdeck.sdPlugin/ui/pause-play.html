The Play/Pause All Players action will play or pause all players. After all players are played or paused, there is an optional sync step that can be performed based on the checkbox above. This is recommended if you are ok with how MultiViewer syncs the players and the data stream. But if you are like me, the dev, and manually sync the data stream, I would turn this off.

Sometimes the image state (the play or pause icon) of the button will not match. This is expected and intentional. It will fix itself after every time this button is pressed.
